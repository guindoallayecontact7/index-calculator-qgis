# AGROGEO AI V2.9.0 — Scientific Core

## Nouveauté
- Scientific Registry: fiches méthodologiques centralisées (formule/méthode, entrées, objectif, hypothèses, limites, statut et base bibliographique/méthodologique).
- Processing Toolbox: algorithme `Scientific Registry — Rapport des méthodes AGROGEO AI` génère un rapport HTML.

## Principe de transparence
Le registre documente les méthodes; il ne certifie pas la justesse de leur implémentation. Les formules, paramètres et traitements doivent être vérifiés par revue scientifique, tests synthétiques et tests sur données réelles.

## Installation
Installer le ZIP comme extension QGIS depuis le gestionnaire d'extensions (`Installer depuis un ZIP`). Activer l'extension, ouvrir Processing Toolbox et rechercher `Scientific Registry`.

## Statut
Compilation Python et intégrité ZIP vérifiées. Exécution dans QGIS non validée dans cet environnement.
